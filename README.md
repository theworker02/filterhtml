# filterhtml

Filter structured JSON html payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/filterhtml/

## Install / run

```bash
git clone https://github.com/theworker02/filterhtml.git
cd filterhtml
node src/cli.js
node --test
```
